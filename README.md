# コタエログ (KotaeLog)

全教科の一問一答を覚えて記録する、スマホ向けの学習アプリ（Liquid Glass UI）。ビルド不要の静的サイトで、GitHub Pages（https://n494n0tk.github.io/KotaeLog-App/）で公開しています。

## 機能

- **教科の切り替え** — 現代国語・英語・生物・化学・地理・歴史。右上の教科ボタンのプルダウンか、サイドバー上部のプルダウンで切り替え。教科ごとにテーマ色が変わり、押した場所から新しい色が広がる
- **単元の選択** — ホームとクイズの上の帯で単元をしぼる（タップでしぼり、続けてタップで足す）。選んだ単元は教科ごとに覚えておき、ホームの習得率・カード・クイズの範囲になる
- **暗記カード** — 範囲を決める画面で単元にチェックをつけ、出すカード（すべて／未学習／未習得／ミスした／覚えた／チェック）・表に出す面・順番（シャッフル／番号順）を選んで始める。めくる画面では、カード右上のチェック、「1枚戻る」（直前の判定を取り消す）、表裏の入れ替え。終わったら「まだ」の分だけもう一度。パソコンではスペースでめくる・→ 覚えた・← まだ・Backspace で1枚戻る
- **4択クイズ** — 語→意味／意味→語／ミックス。5〜30問。連続正解の表示、間違えた問題だけ解き直し
- **一覧** — 語・読み・意味・整理番号で検索、単元・習得状況・チェックで絞り込み、詳細シートで状態と直近の結果を確認
- **苦手** — 間違えた語とチェックをつけた語を自動で集めて復習
- **記録** — 今日の解答数・連続学習日数・累計・正答率、直近14日の解答数グラフ（タップで日ごとの正答率）、単元別／教科別の習得と正答率、最近の解答の履歴。「この教科／全教科」で切り替え
- 学習記録は教科ごとに端末の `localStorage` に保存（解答の履歴は最新8000件まで）。現代文単語アプリ時代の記録は「現代国語」に引き継ぐ
- **左→右スワイプでサイドバー**（画面のどこからでも）。右→左で閉じる
- **スワイプで「戻る」が起きない**：画面端のタッチでブラウザの戻る操作を止め、それでも戻る操作が来たときはページを離れずにサイドバーを開く
- ホーム画面に追加すると全画面アプリ（PWA）として動作
- ライト / ダークモード対応。「視差効果を減らす」設定では動きを止める

## 問題データ

問題はこのリポジトリには置かず、非公開リポジトリ **KotaeLog-Que** に JSON で置いています（書式は KotaeLog-Que の README）。アプリは GitHub API で読みます。

- 設定画面で、KotaeLog-Que だけを読める読み取り専用の Fine-grained token を端末ごとに1回入力します。トークンはその端末の `localStorage` にだけ保存されます
- 読み込んだ問題は端末に保存され、オフラインでも使えます。起動のたびに裏で最新を確認し、変わっていれば反映します
- 問題を足すには、KotaeLog-Que に push するだけです（アプリ側の更新は不要）
- 教科を増やすときも、KotaeLog-Que の `index.json` に1行足して問題ファイルを置くだけです

詳細シート（下から出るポップアップ）は、上の掴み部分を下に引っ張ると閉じます。

学習記録は教科の `id` と `word` をキーに保存されるため、どちらかを書き換えるとその記録はリセットされます。

## ローカルで確認

```sh
npx http-server -p 8080 .
```

## 構成

```
index.html            画面の骨組み
css/style.css         Liquid Glass のスタイル
js/app.js             画面・教科の切り替え・学習記録・演出・スワイプ処理
js/data.js            問題データの読み込み（KotaeLog-Que から）
manifest.webmanifest  PWA 設定
sw.js                 オフライン用（ネットワーク優先）
icons/                アイコン
```
